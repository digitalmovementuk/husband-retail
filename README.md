# Project+ — the app shell

This repository holds **only** the Project+ app shell, published by GitHub Pages at
<https://digitalmovementuk.github.io/husband-retail/tracker/>.

```
index.html          a one-line landing page that sends people to /tracker/
tracker/index.html  the app itself: the sign-in screen and the six screens behind it
tracker/assets/     icons only (browser tab, home screen, the Digital Movement mark)
```

## This repository is PUBLIC. Nothing private may live here.

Everything a signed-in person sees — the programme, the milestones, the roadmap and
deck pictures, the client's logo — is **not in this repository**. It is served, only
after sign-in, by the `pplus-*.php` files on `leads.digitalmovement.uk`.

So, before adding anything here, ask one question: *would I be happy for a competitor
to read this?* If the answer is no, it belongs behind the sign-in, not in this repo.

Never commit here: client strategy, proposals, pricing, target-account lists, contact
details of real people, quarterly reports, or any programme data.
